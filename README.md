# MIEMOU

> 给职业打工人的 AI 项目初始化 Prompt。

## 为什么叫 MIEMOU？

`mie` 是“咩”，`mou` 是“哞”。

一声羊叫，一声牛哞，献给每天认真搬砖的打工人。MIEMOU 是一套让 Agent 快速理解项目、遵循约定、少走弯路的初始化提示词，让它不只是“能写代码”，而是真正逐渐**懂你的项目**。

它不替你搭一套臆想中的技术栈，也不制造复杂流程。你只需要把它交给 Agent，让 Agent 根据项目实际情况完成初始化，把重要的规则、上下文与工作方式沉淀下来。

## 唯一入口

项目初始化只有一个入口：让 Agent 阅读并执行 [MIEMOU.md](MIEMOU.md)。不要根据 README 手动创建脚手架、安装依赖或编写项目文件。

在 Agent 中打开目标项目后，直接发送：

```text
请阅读并严格执行 MIEMOU.md，完成当前仓库的项目初始化，不要提交代码。
```

Agent 会以 `MIEMOU.md` 为准，完成 skill 安装确认、编码规则配置和 `AGENTS.md` 初始化。后续项目技术栈或团队约定发生变化时，先更新 `MIEMOU.md`，再让 Agent 重新执行即可。

- [README.md](README.md)：说明项目理念和使用入口，不承载额外初始化流程。
